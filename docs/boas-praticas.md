# Boas práticas

Se uma etapa se repete em um ponto do fluxo, há 2 formas de você sinalizar:

1. Inserir uma seta para retomada quando próxima ao ponto de repetição.  
2. Inserir elemento Fim com menção ao ponto retomado. 

Evite duplicar etapas anteriores em outros pontos do fluxo, porque isso dificulta a manutenção.
