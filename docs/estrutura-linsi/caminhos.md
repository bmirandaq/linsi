# Camada 3 - Caminhos

Pode existir um único ou mais caminhos.

Posicionar caminhos em linha reta, sempre em sequência da esquerda para a direita.

Continuidade a partir de uma Condição: caminhos comuns, positivos e alternativos seguem em frente; caminhos negativos seguem para baixo.
