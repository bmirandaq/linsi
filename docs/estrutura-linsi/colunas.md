# Camada 2 - Colunas

Colunas devem ser organizadas de cima para baixo, de acordo com a ordem: comum, alternativo, negativo.

Alguns elementos podem coexistir ou ocorrer ao mesmo tempo. Nesse caso, podem ser alinhados verticalmente, com apoio de Nota quando necessário para frisar coexistência.
