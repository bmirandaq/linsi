Links devem ser verificados antes de cada release. Nao registrar rota planejada como existente.

## Regra de uso

Indicar link quando ele oferecer:

- explicacao completa;
- exemplo visual relevante;
- aprofundamento natural;
- referencia oficial util para consulta posterior.

Nao adicionar links mecanicamente a toda resposta.

## Gate de release

Antes de publicar a Skill, validar todas as URLs deste arquivo contra o site em producao e atualizar rotas divergentes.
